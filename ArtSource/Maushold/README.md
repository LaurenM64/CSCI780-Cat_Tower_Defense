# Maushold model

Original stylized four-mouse model built in Blender for this project.
Visual reference: https://sketchfab.com/3d-models/maushold-from-pokemon-scarlet-violet-c9a689709c2c499bb784012c21499262
The reference was viewed for proportions; its mesh and textures were not downloaded or used.

- Editable source: `Maushold.blend` (scene: `Maushold_Studio`).
- Game export: `Assets/Models/Pokemon/Maushold/Maushold.fbx`.
- Four independently visible mouse meshes, about 9,532 triangles total.
- Material colors are assigned in Unity; no texture images are required.
- `MausholdVisualStages` displays 4, 3, 2, or 1 mice at 16, 12, 8, and 4 HP.
- Enemy HP, damage gates, chain weakness, collider, and speed progression are unchanged.
